# Applied GenAI, RAG, Fine-Tuning & AI Agents

A comprehensive, hands-on study curriculum covering modern LLM fine-tuning, parameter efficiency, preference alignment, and production AI agent frameworks.

---

## 🧭 Curriculum Breakdown

### [Track 1: LLM Fine-Tuning, PEFT & Alignment](01-finetuning-and-alignment/README.md)
Focuses on adapting foundation models efficiently using small datasets and lightweight hardware.

- **[Unit 0: Setup & Overview](01-finetuning-and-alignment/unit0/1.md)**: Environment configuration, GPU setups, and tokenizer basics.
- **[Unit 1: Instruction Tuning & SFT](01-finetuning-and-alignment/unit1/1.md)**: Supervised Fine-Tuning mechanics, data preparation, formatting prompts with Chat Templates, and training with `TRL`.
- **[Unit 2: Parameter-Efficient Fine-Tuning (PEFT)](01-finetuning-and-alignment/unit2/1.md)**: LoRA, QLoRA, adapter weight merging, and memory-efficient training.
- **[Unit 3: Preference Alignment](01-finetuning-and-alignment/unit3/1.md)**: Direct Preference Optimization (DPO), Odds Ratio Preference Optimization (ORPO), and reward models.
- **[Unit 4: Vision-Language Models (VLMs)](01-finetuning-and-alignment/unit4/1.md)**: Multimodal foundations, fine-tuning visual models, and image-text understanding.

---

### [Track 2: Autonomous AI Agents & Frameworks](02-agents-and-frameworks/README.md)
Focuses on cognitive agent architectures, tool use, reasoning loops, and multi-agent systems.

- **[Unit 0: Introduction to AI Agents](02-agents-and-frameworks/unit0/introduction.md)**: Defining agents, actions, environments, and agentic workflows.
- **[Unit 1: Agent Mechanics & Structure](02-agents-and-frameworks/unit1/README.md)**: Thoughts, Actions, Observations (ReAct pattern), system prompts, and tool calling.
- **[Unit 2: Agent Frameworks](02-agents-and-frameworks/unit2/introduction.md)**:
  - **[LangGraph](02-agents-and-frameworks/unit2/langgraph/introduction.md)**: Graph-based stateful multi-agent workflows and cyclical reasoning.
  - **[LlamaIndex](02-agents-and-frameworks/unit2/llama-index/README.md)**: Data-connected agents, RAG engines, and knowledge retrieval.
  - **[smolagents](02-agents-and-frameworks/unit2/smolagents/introduction.md)**: Lightweight Python code-first agents and fast tool execution.
- **[Unit 3: Real-World Use Cases](02-agents-and-frameworks/unit3/README.md)**: Web search agents, SQL querying agents, and multi-tool orchestration.
- **[Unit 4: Benchmarking & Evaluation](02-agents-and-frameworks/unit4/introduction.md)**: Evaluation frameworks, GAIA benchmark testing, and reliability monitoring.
- **Bonus Units**: [Bonus 1](02-agents-and-frameworks/bonus-unit1/introduction.md), [Bonus 2](02-agents-and-frameworks/bonus-unit2/introduction.md), [Bonus 3](02-agents-and-frameworks/bonus-unit3/introduction.md).
