# Applied GenAI, RAG, Fine-Tuning & AI Agents

A comprehensive, hands-on study curriculum covering modern LLM fine-tuning, parameter efficiency, preference alignment, and production AI agent frameworks.

---

## 🧭 Curriculum Breakdown

### Track 1: LLM Fine-Tuning, PEFT & Alignment (`01-finetuning-and-alignment/`)
Focuses on adapting foundation models efficiently using small datasets and lightweight hardware.

- **[Unit 0: Setup & Overview](01-finetuning-and-alignment/unit0/)**: Environment configuration, GPU setups, and tokenizer basics.
- **[Unit 1: Instruction Tuning & SFT](01-finetuning-and-alignment/unit1/)**: Supervised Fine-Tuning mechanics, data preparation, formatting prompts with Chat Templates, and training with `TRL`.
- **[Unit 2: Parameter-Efficient Fine-Tuning (PEFT)](01-finetuning-and-alignment/unit2/)**: LoRA, QLoRA, adapter weight merging, and memory-efficient training.
- **[Unit 3: Preference Alignment](01-finetuning-and-alignment/unit3/)**: Direct Preference Optimization (DPO), Odds Ratio Preference Optimization (ORPO), and reward models.
- **[Unit 4: Vision-Language Models (VLMs)](01-finetuning-and-alignment/unit4/)**: Multimodal foundations, fine-tuning visual models, and image-text understanding.

---

### Track 2: Autonomous AI Agents & Frameworks (`02-agents-and-frameworks/`)
Focuses on cognitive agent architectures, tool use, reasoning loops, and multi-agent systems.

- **[Unit 0: Introduction to AI Agents](02-agents-and-frameworks/unit0/)**: Defining agents, actions, environments, and agentic workflows.
- **[Unit 1: Agent Mechanics & Structure](02-agents-and-frameworks/unit1/)**: Thoughts, Actions, Observations (ReAct pattern), system prompts, and tool calling.
- **[Unit 2: Agent Frameworks](02-agents-and-frameworks/unit2/)**:
  - **[LangGraph](02-agents-and-frameworks/unit2/langgraph/)**: Graph-based stateful multi-agent workflows and cyclical reasoning.
  - **[LlamaIndex](02-agents-and-frameworks/unit2/llama-index/)**: Data-connected agents, RAG engines, and knowledge retrieval.
  - **[smolagents](02-agents-and-frameworks/unit2/smolagents/)**: Lightweight Python code-first agents and fast tool execution.
- **[Unit 3: Real-World Use Cases](02-agents-and-frameworks/unit3/)**: Web search agents, SQL querying agents, and multi-tool orchestration.
- **[Unit 4: Benchmarking & Evaluation](02-agents-and-frameworks/unit4/)**: Evaluation frameworks, GAIA benchmark testing, and reliability monitoring.
- **Bonus Units**: [Bonus 1](02-agents-and-frameworks/bonus-unit1/), [Bonus 2](02-agents-and-frameworks/bonus-unit2/), [Bonus 3](02-agents-and-frameworks/bonus-unit3/).
