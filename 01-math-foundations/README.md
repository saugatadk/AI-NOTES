# Mathematical Foundations for Machine Learning

A comprehensive self-study reference covering the core mathematical concepts that underpin machine learning, deep neural networks, and optimization algorithms.

---

## 📚 Curriculum Breakdown

### Part 1: Mathematical Foundations
1. **Linear Algebra**: Vectors, matrices, vector spaces, linear independence, basis, rank, linear mappings, and affine spaces.
2. **Analytic Geometry**: Norms, inner products, lengths, distances, angles, orthogonality, orthonormal basis, orthogonal projections, and rotations.
3. **Matrix Decompositions**: Determinant, trace, eigenvalues, eigenvectors, Cholesky decomposition, Eigendecomposition, and Singular Value Decomposition (SVD).
4. **Vector Calculus**: Differentiation of univariate functions, partial derivatives, gradients, Jacobians, Hessians, vector/matrix chain rule, and backpropagation mechanics.
5. **Probability & Distributions**: Sample spaces, random variables, conditional probability, Bayes' theorem, independence, means, variances, common distributions (Gaussian, Bernoulli, etc.), and conjugate priors.
6. **Continuous Optimization**: Unconstrained optimization, gradient descent, Newton's method, constrained optimization, Lagrange multipliers, and duality.
